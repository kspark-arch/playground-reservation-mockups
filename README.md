# 운동장 사용 예약 시스템 P0

학생·교직원과 운영자가 운동장 예약 현황을 확인하고 신청·승인·수정·취소할 수 있는 로컬 시연용 웹 애플리케이션입니다.

## 실행 방법

1. 프로젝트 폴더의 `index.html`을 더블클릭합니다.
2. Chrome 또는 Edge에서 페이지가 열리면 바로 사용할 수 있습니다.
3. 별도 프로그램 설치, 개발 서버, 인터넷 연결은 필요하지 않습니다.

브라우저 보안 설정으로 직접 실행이 제한되는 특수한 환경에서는 Chrome 또는 Edge에서 `index.html`을 직접 열어 주세요.

## 시연 계정

모든 계정의 비밀번호는 `1234`입니다.

- 학생: `20260001`
- 교직원: `staff001`
- 운영자: `operator`
- 최고관리자: `admin`

계정과 비밀번호는 기능 확인용이며 실제 보안 인증이 아닙니다.

## 주요 기능

- 비로그인 예약 현황 조회
- 학번·사번 기반 시연 로그인과 역할별 메뉴
- 월간 달력과 날짜별 1시간 슬롯 조회
- 운동장·농구코트 복수 선택 가능, 동일 시설의 전체와 하프는 동시 선택 불가
- 예약 신청 및 중복 시간 차단
- 신청자 이름과 연락처 필수 입력
- 전월 20일 오픈, 월 1회, 최대 2시간 등 정책 검증
- 본인 예약 수정·취소
- 운영자 승인·반려·취소 및 검색
- 사용자와 관리자 간 1:1 문의 메시지
- 사용 완료 예약의 별점 및 이용 후기
- 운영자 전용 알림 메뉴와 승인 안내 문구 자동 생성
- 신규·수정 예약 접수 시 운영자 승인 요청 알림
- 정규수업·훈련·행사·점검 반복 우선 배정
- 예약 및 관리자 작업 이력
- 모바일 하단 빠른 메뉴와 스마트폰 최적화 화면
- 반응형 화면과 키보드 접근성

## 권장 시연 순서

1. 로그인하지 않고 `예약 현황`에서 공개 상태를 확인합니다.
2. 학생 계정으로 로그인하고 빈 시간대를 선택해 예약을 신청합니다.
3. 로그아웃한 뒤 운영자 계정으로 로그인합니다.
4. `예약 관리`에서 방금 신청한 예약을 승인하거나 반려합니다.
5. 학생 계정으로 다시 로그인해 `내 예약`에서 상태를 확인하고 수정·취소합니다.
6. 운영자 계정의 `우선 배정`에서 반복 일정을 미리보기 후 등록합니다.
7. `작업 이력`에서 위 작업의 처리 기록을 확인합니다.

## 데이터 저장과 초기화

데이터는 브라우저 `localStorage`의 `groundReservationP0` 항목에 저장됩니다. 새로고침하거나 브라우저를 닫아도 같은 브라우저에서는 유지됩니다.

초기화 방법:

1. 시작 화면 아래의 `시연 데이터 초기화`를 선택합니다.
2. 확인 창에서 `초기화`를 선택합니다.

초기화하면 추가한 예약, 우선 일정, 작업 이력이 삭제되고 기본 시연 데이터로 돌아갑니다.

## 자체 점검

`tests.html`을 더블클릭하면 실제 브라우저에서 다음 흐름을 자동 점검합니다.

- 초기 데이터와 역할별 계정
- 일반 사용자 로그인
- 예약 신청과 승인 대기
- 최대 예약 시간 정책
- 운영자 승인
- 작업 이력
- 우선 배정 등록
- 승인 슬롯 중복 차단

점검 중 사용한 데이터는 완료 후 이전 localStorage 값으로 복원됩니다.

## 기본 예약 정책

- 운영 시간: 09:30~18:30
- 예약 단위: 1시간
- 시작 시간: 1교시(09:30)~8교시(16:30)
- 1회 최대 시간: 2시간
- 사용자당 월 예약 횟수: 제한 없음
- 취소 마감: 사용 시작 24시간 전
- 다음 달 예약 오픈: 전월 20일 00:00
- 일반 예약: 운영자 승인 필요
- 시간 기준: 한국 시간

정책은 `assets/app.js`의 초기 `rules` 데이터에 정의되어 있습니다.

## 로컬 시연 버전의 한계

이 버전은 HTML 파일을 직접 실행하기 위한 단일 브라우저 프로토타입입니다.

- 여러 PC나 브라우저 사이에 데이터가 공유되지 않습니다.
- 동일한 PC에서도 브라우저 프로필이 다르면 데이터가 분리됩니다.
- 비밀번호와 권한 검사가 브라우저 코드에 있으므로 보안 기능으로 사용할 수 없습니다.
- 여러 사용자의 실제 동시 요청을 원자적으로 차단할 수 없습니다.
- 실제 문자·카카오 알림톡은 발송되지 않으며 생성된 문구를 복사하는 시연 방식입니다.
- 브라우저 데이터 삭제 시 예약 데이터도 삭제됩니다.

실제 운영 전에는 서버 인증, API, PostgreSQL의 트랜잭션 및 unique constraint, HTTPS, 백업과 개인정보 보호 체계를 갖춘 운영 시스템으로 전환해야 합니다.

## 파일 구성

- `index.html`: 애플리케이션 실행 파일
- `assets/styles.css`: 화면 스타일과 반응형/접근성 처리
- `assets/app.js`: 데이터, 로그인, 예약, 관리자 기능
- `assets/brand/`: 연성대학교 공식 UI(심볼·시그니처·엠블럼) 이미지
- `thumbnail-ground-reservation.png`: 공유용 섬네일
- `tests.html`: 브라우저 자동 점검
- `운동장_사용_예약_시스템_구축_개발문서.md`: 원본 요구사항 문서

화면 색상은 연성대학교 전용색(Magenta / Blue / Green / D.Gray)을 기준으로 적용했습니다.
